# md-2-beauty

An open source tool to convert Markdown to HTML, DOCX, and PPTX with theme support and compatibility with Markdown extensions. Uses Python's `markdown` library for core parsing and Node.js for rendering JS-based diagrams (e.g., Mermaid).

## Features
- Convert Markdown to HTML, DOCX, PPTX
- Theme support for output formats
- Supports Markdown extensions (via `markdown` library)
- Mermaid and other JS-based diagram support (via Node.js)
